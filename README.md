# Davi Rangel Portfolio

Bilingual professional portfolio built with Nuxt 4, Vue 3, TypeScript, and Nuxt I18n.

## Stack

- Nuxt 4 and Vue 3
- TypeScript
- `@nuxtjs/i18n` with English as the default locale
- `@nuxt/icon` with local Lucide icons
- Server-side rendering and localized SEO metadata

## Routes

- `/` - English (default)
- `/pt` - Portuguese

## Development

The current Nuxt release requires Node `^22.22.3`, `^24.15.0`, or `>=26.0.0`.

```bash
cd frontend
npm install
npm run dev
```

## Quality checks

```bash
npm run typecheck
npm run build
```
